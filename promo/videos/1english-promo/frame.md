# Дизайн-система ролика — apple-keynote-dark

Бренда два: интерфейс платформы (он в кадре как есть) и сцена вокруг него.
Сцена не спорит с интерфейсом — она темнее его и почти без деталей.

## Цвет

| Роль | Значение |
|---|---|
| Сцена (canvas) | `#05080E` |
| Свечение сверху-слева | `rgba(90,155,234,.55)` → 0 |
| Свечение снизу-справа | `rgba(242,100,127,.40)` → 0 |
| Свечение на сцене игр | `rgba(75,201,138,.26)` → 0 |
| Текст | `#F3F7FC` |
| Второй текст | `#8FA0B4` |
| Акцент действия | `#5A9BEA` (кикеры, ссылка) |
| Акцент числа | `#F2647F` |
| Верно | `#4BC98A` |

Работа каждого цвета: синий — «здесь действие», красный — «здесь число»,
зелёный — «здесь результат». Больше цветов на сцене нет.

## Типографика

Golos Text (шрифт самой платформы), подключён локально.

- Кикер: 30px / 700 / трекинг .22em / uppercase / синий
- Заголовок: 104px (короткий) или 88px (длинный) / 800 / трекинг −.035em
- Подзаголовок: 40px / 500 / `#8FA0B4`, максимум 820px ширины
- Подпись под устройством: 34px / 600

## Кадр

- 1080×1920, 30 fps.
- Текстовый блок — сверху, от 150px, по центру; боковое поле 80px.
- Устройство — по центру, ширина 600px, верх 560px. Экран 560×1260,
  радиус 48px, тень вниз и синий ореол 16%.
- «Чёлки» нет: в кадре реальные скриншоты, накладка перекрывала бы их шапку.

## Движение

- Вход текста: кикер y +22 → 0 за 0.45s, строка y +44 и scale .985 → 1 за
  0.6s со сдвигом 0.08s, подпись — ещё через 0.12s. Всё на `power3.out`.
- Уход текста: y −28, opacity → 0, `power2.in`, 0.38s, плюс жёсткий
  `tl.set` на границе клипа.
- Нажатие (функция `tap` в композиции): подсветка кнопки 0.1s → круг от
  пальца scale .35 → 1 → 2.1 с затуханием 0.42s → провал устройства до
  scale .993 и обратно. Экран меняется через 0.15s после нажатия.
- Устройство: выезд снизу с наклоном `rotationX` 10° → 0, `expo.out` 1.0s,
  дальше дрейф ±12px.
- Экраны внутри устройства: растворение 0.3–0.36s или сдвиг по x 0.45–0.5s —
  сдвиг там, где в жизни свайп или переход на другую вкладку.
- Ничего не мигает и не дрожит: только opacity, x/y, scale, rotation,
  backgroundColor и color.

## Звук

- Музыка одна, −14 LUFS на мастере, вход 2.2s, уход 2.6s, просадка до 0.2
  на моменте «Верно».
- SFX только там, где на экране что-то произошло: смена экрана, касание,
  верный ответ, выезд устройства, финал.
