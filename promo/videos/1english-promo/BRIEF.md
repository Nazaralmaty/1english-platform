# Бриф

**Что снимаем.** Презентацию платформы 1English для учеников: как она
выглядит и что в ней есть. Формат — не «рилс с монтажными ударами», а
спокойная презентация приложения: тёмная сцена, устройство в кадре,
крупная типографика, экраны меняются сами.

**Источник визуала.** Живые экраны платформы `~/1english-platform`,
снятые в браузере на вьюпорте 390x844 при DPR 3 (шоты — `promo/shots/`).
Ничего не перерисовано: в кадре реальный интерфейс.

**Звук.** Голоса нет. Музыка — одна дорожка из локальной библиотеки,
поверх точечные ui-звуки на смену экранов и на верный ответ.

**Что обязательно показать.** Вход по номеру, курс и процент, три шага
урока (Урок / Задание / Словарь), ответ тапом, карточку словаря, три
игры, светлую и тёмную тему, профиль, работу без сети, адрес платформы.

**Чего нет.** Придуманных цифр, отзывов, выдуманных ссылок. Все числа —
из README платформы (4 уровня, 56 уроков, 14 уроков в уровне).
