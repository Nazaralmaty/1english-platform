# 1English · платформа обучения (прототип)

Личное пространство ученика **между** групповыми Zoom-уроками: бейнесабақ,
словарь с повторением, упражнения, игры, прогресс. Группа остаётся в Zoom —
платформа её не заменяет.

Открывается по ссылке на любом телефоне: обычные HTML-файлы, без сборки,
без CDN, без установки. Данные — в `localStorage`.

**Одна ссылка на всё:** [`index.html`](index.html) — стенд с прямыми ссылками
на каждый экран. Демо-маршрут: `bala/kiru.html` → диагностика → сабақ → ойын.

## Что где

| Папка | Что это |
|---|---|
| [`bala/`](bala/) | экраны ученика: кіру, бүгін, диагностика, жол, сабақ, сөздік, ойын, тапсырма, профиль |
| [`games/`](games/) | три арены: Flappy English (перенос из StudyLine), сөз сұрыптау, сөйлем құрастыр |
| [`ustaz/`](ustaz/) | кабинет учителя: кто сделал домашку, чьё голосовое не прослушано |
| [`ata/`](ata/) | кабинет родителя: неделя одной карточкой и фраза, которую сказать ребёнку |
| [`data/`](data/) | контент: курс на 24 юнита, 48 слов, юнит u1 целиком, банк диагностики |
| [`media/`](media/) | видеоурок u1 (66 с) + скрипт сборки: озвучка локальной моделью, слайды, ffmpeg |
| [`backend/`](backend/) | `schema.sql` для Supabase и `export.mjs` → `seed.sql` |

## Перед показом — одна команда

```bash
node check.mjs              # все экраны
node check.mjs sabaq oiyn   # только названные
```

Открывает каждый экран в настоящем Chrome на 390×844, гоняет его `?test=1`,
ловит ошибки консоли, битые ссылки и картинки. Второй проход — **360×640**:
у детей в регионах телефоны уже, и вёрстку, которая держится только на
большом экране, на своём телефоне не увидишь.

Отдельно проверяется то, чего не видит ни один внутренний тест:
у каждого готового юнита ровно 8 слов, а видеоурок реально доигрывает до
чекпоинта и чекпоинт останавливает видео вопросом (разъехавшиеся секунды в
`data/lesson_u1.js` ловятся именно здесь).

Сейчас: **14 блоков теста, 0 проблем.**

Если `puppeteer-core` не установлен — один раз:
```bash
npx -y puppeteer-core@23 --version
```

## Как устроено обучение

Недельная петля привязана к Zoom-группе:

```
Сабаққа дейін      →   Zoom-сабақ        →   Сабақтан кейін
8 сөз + бейне          (вне платформы)       4 жаттығу + ойын + дауыс
                              ↓
        Күнделікті қайталау — 3 мин, очередь Лейтнера, стрик
```

- **CEFR в can-do-формулировках**: не «уровень A2», а «Мен өз күнім туралы айта аламын».
- **Разнесённое повторение**: слово не «выучено», а стоит в очереди повторов.
- **Task-based**: юнит закрывается задачей, а не темой грамматики.
- **Речь слушает человек**: ребёнок пишет голосовое, ұстаз слушает и отмечает.
  Автопроверки произношения нет намеренно.

## Видеоурок

`media/u1_sabaq.mp4` — 66 секунд, 22 слайда, казахская озвучка локальной
моделью (`~/ai-local/models/kazakh-omnivoice`, скилл `local-tts`), сборка
ffmpeg. Пересобрать после правки текста:

```bash
cd media
bash script/tts.sh kk script/kk.txt vo --gender male --tempo 1.05
node script/render.mjs 22
bash script/build.sh
```

Длительность слайда берётся из реального WAV, а не прикидывается; секунды
чекпоинтов в `data/lesson_u1.js` выставлены по фактической склейке.

## Что осознанно не сделано

- **Сервера нет.** Всё живёт на одном устройстве: прогресс не переезжает на
  другой телефон, ұстаз слышит только голосовое с этой же машины, а **правильные
  ответы лежат в исходнике страницы**. Пока это так, платформу нельзя дать
  чужому ребёнку. Лечится `backend/schema.sql`: там `en_questions` закрыта RLS
  наглухо, наружу смотрит вью без ответа, а проверку делает функция `en_answer()`.
- **Контент написан на 6 юнитов из 24**, целиком — только u1. Остальные 18
  честно показаны замком, а не поддельным прогрессом.
- **Список группы у ұстаза — константа** с пометкой `demo:true`, посещаемость
  Zoom у родителя — одна явная константа. Выдуманных правдоподобных чисел нет.
- **Русская локализация** заведена в словаре (`assets/app.js`, переключатель в
  профиле), но контент курса пока только на казахском.
- **Нет**: оплат, видеозвонков внутри платформы, ИИ-тьютора, автопроверки
  произношения, мобильного приложения.

## Дальше

1. Завести проект Supabase → выполнить `backend/schema.sql`, затем
   `node backend/export.mjs > backend/seed.sql` и залить seed.
2. Заменить тело `App.load/App.save` в `assets/app.js` на вызовы Supabase —
   экраны при этом не трогаются, они ходят только через `App.*`.
3. Вход по телефону включить в Supabase Auth (phone provider), без email.
4. Дописать контент юнитов u2–u6 по образцу `data/lesson_u1.js`.
