# 1English · платформа обучения (прототип)

Личное пространство ученика **между** групповыми Zoom-уроками: уроки с
видео и упражнениями, словарь с повторением, арены, ежемесячный адаптивный
тест, кабинеты ұстаз и ата-ана. Группа остаётся в Zoom — платформа её не
заменяет и не продаёт: внутрь входит только тот, кто уже учится.

Открывается по ссылке на любом телефоне: обычные HTML-файлы, без сборки,
без CDN, без установки. Данные — в `localStorage`.

**Одна ссылка на всё:** [`index.html`](index.html) — стенд со ссылками на
каждый экран. Демо-маршрут: `bala/kiru.html` → выбор уровня → урок → арена.

## Два курса

| Курс | CEFR | Кому | Готово |
|---|---|---|---|
| **Beginner** | pre-A1 → A1 | «сөздерді танимын, сөйлем құрай алмаймын» | 6 уроков, 2 модуля |
| **Elementary** | A1 → A2 | «түсінемін, бірақ сөйлей алмаймын» | 6 уроков, 2 модуля |

Уровень выбирает **сам ученик** (`bala/dengey.html`) и может сменить в любой
момент — прогресс привязан к уроку, а не к уровню, поэтому ничего не теряется.
Входная диагностика только советует.

Beginner не начинается с «My name is»: дети учат английский и в школе, и как
себя зовут знают. Стартуем с того, что реально ломается в речи — `to be` в
отрицании и вопросе, `have got`, разница «делаю вообще» и «делаю сейчас».
Elementary — прошедшее время, вопросы к нему, сравнение, планы, вежливые
просьбы и связки, которыми держится разговор.

Урок = 4 шага (видео добавляет пятый): слова → упражнения → арена → тест,
плюс необязательное голосовое задание, которое слушает ұстаз.
Шесть типов упражнений: сопоставление, пропуск, аудирование, порядок слов,
поиск ошибки, письмо.

## Ежемесячный тест с эскалацией

`bala/ai_test.html` — порт игрового теста из `youngfuture-games/templates`,
из которого вырезаны форма заявки, отправка наружу и внешние картинки.

Сначала пробный блок из 8 вопросов, по нему считается взвешенный балл, и
дальше ребёнок уходит в ветку **easy / core / hard**. Вместе со сложностью
меняется и формат: в hard появляются чтение, cloze и категоризация. Итог —
уровень (Beginner … Upper-Intermediate) и разбивка по A1/A2/B1/B2; результат
виден ученику, родителю и ұстазу.

## Перед показом — одна команда

```bash
node check.mjs               # все экраны
node check.mjs sabaq oiyn    # только названные
```

Открывает каждый экран в настоящем Chrome на 390×844, гоняет его `?test=1`,
ловит ошибки консоли, битые ссылки и картинки. Второй проход — **360×640**:
у детей в регионах телефоны уже.

Отдельно проверяется то, чего не видит ни один внутренний тест: у каждого
готового урока ровно 8 слов и написанное содержимое, а видеоурок реально
доигрывает до чекпоинта и чекпоинт останавливает видео вопросом.

Сейчас: **17 блоков теста, 0 проблем.**

Если `puppeteer-core` не установлен — один раз:
```bash
npx -y puppeteer-core@23 --version
```

## Видео и озвучка

`media/u2_sabaq.mp4` — 49 секунд, 10 слайдов, казахская озвучка. Презентация
к уроку живёт отдельно и открывается двойным кликом:
[`media/u2/prezentaciya.html`](media/u2/prezentaciya.html) — стрелки листают.

**Голос один на всю платформу.** Модель OmniVoice умеет клонировать по
образцу, поэтому голос больше не «какой выпадет»: образец выбран Элжаном и
лежит в `media/voice/ustaz.wav` вместе с расшифровкой. Второй голос (ата)
добавляется файлом в ту же папку и флагом `--voice`.

```bash
cd media
~/ai-local/.venv/bin/python script/vo_kk.py script/kk_u2.txt u2/vo \
  --instruct "Живо и с интересом, как учитель"
node script/shot_u2.mjs      # слайды презентации → PNG
bash script/build_u2.sh      # сборка + печать таймингов слайдов
```

Длительность слайда берётся из реального WAV, темп речи поднимается на 10 %
(ровный TTS звучит вяло), а секунды чекпоинтов в `data/lessons_b.js`
выставлены по фактической склейке.

## Что осознанно не сделано

- **Сервера нет.** Всё живёт на одном устройстве: прогресс не переезжает на
  другой телефон, ұстаз слышит только голосовое с этой же машины, а
  **правильные ответы лежат в исходнике страницы**. Лечится
  `backend/schema.sql`: `en_questions` закрыта, наружу смотрит вью без ответа,
  проверку делает функция `en_answer()`. Схема и seed прогнаны на настоящем
  Postgres 16 — под ролью ученика банк вопросов недоступен, вью отдаёт 95
  вопросов без `correct_index`.
- **Видео одно** — ко второму уроку Beginner. Остальные уроки честно показывают
  четыре шага вместо пяти, а не пустой плеер.
- **Контент — 12 уроков из 18.** Третьи модули каждого уровня помечены замком.
- **Список группы у ұстаза — константа** с пометкой `demo:true`, посещаемость
  Zoom у родителя — одна явная константа. Выдуманных чисел нет.
- **Русская локализация** заведена в словаре (`assets/app.js`), но контент
  курса пока только на казахском.
- **Нет**: оплат, видеозвонков внутри платформы, автопроверки произношения,
  мобильного приложения.

## Дальше

1. Завести проект Supabase → выполнить `backend/schema.sql`, затем
   `node backend/export.mjs > backend/seed.sql` и залить seed.
2. Заменить тело `App.load/App.save` в `assets/app.js` на вызовы Supabase —
   экраны при этом не трогаются, они ходят только через `App.*`.
3. Вход по телефону включить в Supabase Auth (phone provider), без email.
4. Дописать уроки третьих модулей по образцу `data/lessons_b.js`.
