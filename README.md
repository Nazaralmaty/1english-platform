# 1English · платформа обучения

Личное пространство ученика между групповыми Zoom-уроками: три уровня,
уроки с видео и разбором правила, задания, словарь и игры. Группа остаётся
в Zoom, платформа её не заменяет.

Открывается по ссылке на любом телефоне: обычные HTML-файлы, без сборки,
без внешних CDN, без установки. Прогресс пока в `localStorage`.

Открыта: **https://nazaralmaty.github.io/1english-platform/**
Маршрут ученика: номер телефона → выбор уровня → уроки.

## Экраны

| Экран | Что на нём |
|---|---|
| Вход | номер телефона и код. Email не спрашиваем. |
| Уровень | четыре кнопки. Нажал — короткое описание и «Выбрать». |
| Уроки | обложка уровня, общий процент, 14 уроков. Урок раскрывается на месте. |
| Урок | три шага и других нет: **Урок**, **Задание**, **Словарь**. |
| Игры | Flappy English, порядок слов, сортировка. Слова берутся из уровня ученика. |
| Профиль | имя, дата рождения, пол, фото, язык интерфейса, тема оформления. |

Внизу три вкладки: Уроки, Игры, Профиль. Уровень меняется нажатием на
обложку курса.

Тема — светлая, тёмная или системная. Язык интерфейса — русский или
казахский; содержание уроков пока только на русском.

## Курс

Четыре уровня по 14 уроков: Beginner (A1), Elementary (A1+),
Pre-Intermediate (A2), Intermediate (B1). Всего 56 уроков.

Пустой урок — нормальное состояние: он виден в списке, но внутрь не
пускает, пока к нему не привязали видео или задания. Сейчас заполнены
14 роликов Beginner и урок Elementary 2 «Can / can’t» целиком: правило,
8 слов и 6 заданий.

Задания двух типов: выбор варианта и сборка предложения из слов.
Клавиатура не нужна нигде, всё решается тапом.

## Как добавить видео к уроку

Ролики на YouTube закрытые (unlisted): по ссылке открываются, в поиске их
нет. Плееру нужен только id — хвост ссылки после `youtu.be/`.

Из `https://youtu.be/3ZkombMruHM` берётся `3ZkombMruHM` и вставляется в
`app/course.js`, в таблицу `window.VIDEOS`:

```js
window.VIDEOS = {
  b1:'rGaqiSrDJKA',  b2:'pyqn323rv2Q',  …
  e1:'',  e2:'3ZkombMruHM',  …
};
```

Ключ — id урока: `b` Beginner, `e` Elementary, `p` Pre-Intermediate,
`i` Intermediate, дальше номер от 1 до 14. Больше нигде править не нужно.

## Как добавить материалы урока

Дописать объект в `window.CONTENT` того же файла — тема, правило,
примеры, слова, задания. Заготовка лежит там же в комментарии. Урока нет
в `CONTENT` — значит он пустой, и его шаги закрыты.

## Проверки

```bash
node app/check.mjs          # данные курса и банк слов для игр
open "index.html?test=1"    # экраны: смотреть консоль
```

`check.mjs` ловит то, что ломается опечаткой: индекс верного ответа за
пределами вариантов, задание, из слов которого не собирается ответ, урок
без слота под видео, группу слов из одного слова.

## База данных

Вход — по номеру телефона и коду из шести цифр: аккаунт заводится сам при
первом входе, второй раз тот же код пускает внутрь. Профиль и прогресс
уезжают в Supabase, на экране при этом всегда локальное состояние —
приложение работает и без сети, копия уедет при следующем сохранении.

Чтобы это заработало, схему надо один раз применить:
[`backend/supabase_min.sql`](backend/supabase_min.sql) → Supabase → SQL
Editor → Run. Пока таблиц нет, вход работает, а данные ложатся только на
телефон.

anon-ключ лежит в [`app/db.js`](app/db.js) открыто и так задумано: доступ
дают не ключи, а правила RLS — ученик читает и пишет только свои строки.

## Границы прототипа

Правильные ответы лежат рядом с вопросами в `app/course.js`, то есть видны
через «просмотр кода». Код входа из шести цифр подбирается перебором.
Полная схема на вырост — [`backend/schema.sql`](backend/schema.sql), там
решение: индекс верного ответа не уходит клиенту, сервер отвечает
«верно / неверно» по одному вопросу.

Путь до production ready, по шагам — [`РАЗВЁРТЫВАНИЕ.md`](РАЗВЁРТЫВАНИЕ.md).
